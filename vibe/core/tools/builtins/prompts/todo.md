Track tasks for the current session. Use for multi-step work. Write the list as soon as the steps are known, then keep it current as work progresses: after each step finishes, mark it completed and the next one in_progress — never save updates for the end. `action: "write"` replaces the full list — include every item you want to keep. Inside a long-running `run_typescript` program, do the same through `tools.vibe.todo` so the list advances while the program runs.
