# What's new in v2.23.2

- **`vibe mcp add`/`remove`**: Add and remove remote MCP servers from the shell without editing TOML by hand.
- **Auto theme**: Vibe now follows your terminal/OS light/dark appearance automatically with theme "auto" (default).
- **Redesigned /config**: A searchable, full-screen settings browser with per-layer origin display and typed edit modals
- **Skill creator**: A built-in `skill-creator` skill that guides you through authoring your own skills
