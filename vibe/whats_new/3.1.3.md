- **Stash a draft**: press `Ctrl+S` to set your draft aside, send another message, and get the draft back
- **Goals**: `/goal <objective>` keeps Vibe working on a task across turns until it is done, with an optional token budget. `Esc` pauses it and `/goal resume` picks it up again
- **Loop manager**: type `/loop` to review, delete, and add scheduled loops, and see the next one above the input
- **Trusted folders**: review, change and add folder trust decisions with `/trusted-folders`
- **Mistral Large 4**: now the default model
